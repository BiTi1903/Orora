# Mobile navigation and catalog filters

Mobile (up to 768px) has four fixed links: Trang chủ, Danh mục, Sản phẩm, Tra cứu. Categories open a bottom sheet backed by the existing category records. The bar accounts for safe areas and its actual height, reserves space under the page, moves floating controls above it and hides while dialogs/chat are open.

Admin locations:
- Visual Builder → Navbar → Thanh điều hướng dưới — mobile: enable/disable, individual links, labels, colors, typography and sizes, with an embedded preview.
- Visual Builder → Sản phẩm / Collection → Tìm kiếm và bộ lọc sản phẩm: enable/disable, criteria, labels, typography, colors, layout and page size. Existing save flow persists nested navStyles.mobile and collectionStyles.filters.
- Category records remain managed in the existing product/category admin.

Filters support accent-insensitive product name/ID search, categories, volume, numeric price ranges, quote-only prices, sorting, and grid/carousel views. URLs retain filters and unrelated query parameters. Filtering compares actual variant prices; a 100k/500k product does not match a 200k–300k range. Unknown prices are never interpreted as zero. Grid mode paginates (12 products by default); automatic layout uses a grid when filtering or when the catalog exceeds 12 products. Filtering does not rewrite product identities or URLs.

No database migration or additional API endpoint is required. Catalog filtering currently uses the existing downloaded product list; server-side indexed pagination can be added if the catalog grows enough to make that download expensive.

Validation: 217 unit tests, ESLint, production build and bundle budget passed. Browser coverage includes the new navigation, category routing, floating chat spacing, filter combinations, pagination, and admin preview at 320/390/768/1440px. Production Firebase saves and Vercel deployment status require verification in the connected production account.

The mobile bar now supports an ordered list of up to six editable items in Visual Builder → Navbar → Thanh điều hướng dưới — mobile. Each item has its own label, icon, visibility and destination (home, Story, products, newsletter, footer, lookup or a custom URL). Legacy four-item settings remain the fallback until an item list is saved. Empty lists intentionally hide the bar. Custom links accept local paths, HTTPS/HTTP, mailto and tel; script and protocol-relative URLs are rejected. Newsletter has the public anchor #newsletter; footer uses #contact.

## Cart
The bottom navigation includes a cart entry with quantity badge. Product cards have an add icon beside the detail link. Multiple volumes require a choice; a sole volume defaults automatically. Cart lines store only product ID, variant ID and quantity in local storage; current catalog data supplies names and prices. Matching variants merge up to the existing 20-unit limit. The compact panel supports quantity edits, removal and a Details action. Details navigates to the canonical product route with the selected variant and quantity in router state; the detail page validates the incoming selection against the current product options. Checkout starts from the detail page. Cart subtotals exclude shipping; unavailable products/variants cannot be checked out. Admin → Visual Builder → Navbar → Thanh điều hướng dưới → Giỏ hàng exposes content, typography, visibility and animation settings. Reduced-motion users receive no fly animation.

The catalog toolbar uses a single filter trigger on desktop and mobile. Basic filtering now consists of search, category, price range and sorting; volume/price-kind controls have been removed. Tracking uses a compact single-column search panel with optional help collapsed below it. Existing typography and copy settings remain in use.

The visible filter form now only exposes category and minimum/maximum price. Search, volume and sorting URL criteria are ignored in the public collection. Mobile drawer defaults to 50vw (admin widthPercent 40–80). Cart rows use a compact image/body layout, right-aligned prices and a separate quantity/action row.

The cart can now open as a nonmodal glass dialog so the page behind it remains scrollable (cart.backgroundScroll, default true). Outside taps and Escape close it; a background swipe does not. Other dialogs retain modal scroll locking. The cart quantity control has minus/input/plus buttons. Mobile nav icons rotate on activation (mobile.spin); reduced-motion users skip rotation. Chat fixes its position after initial layout, reserves room above back-to-top, and stretches during dragging before docking at a screen edge. The side menu closes through its outside overlay or Escape and no longer shows a separate X button.

All shared glass surface/button effects are now restricted to screens up to 768px; desktop uses the existing normal appearance. Chat droplet stretching is also mobile-only. Product card price/action layout fixes apply to both sizes: prices get a separate unbroken line, and the detail/cart action row is capped on desktop.

Catalog controls now expand inline beneath the filter trigger rather than opening a modal. The result count is removed. Product card default action text is “Xem”; legacy saved “Xem chi tiết” labels render as “Xem”, while other custom labels remain editable. Catalog prices no longer prefix “Từ”. Price and actions share a compact row where space permits, wrapping on narrow cards to avoid squeezing currency text.

On the mobile home page, the bottom navigation now starts hidden/inert and reveals after a small downward scroll as soon as the marquee's bottom fits above the bar with a 12px gap; the marquee can still be visible on screen. Scrolling back until the bar would overlap the marquee hides it again. If the marquee is absent, the hero is used as the boundary. Other routes keep the bar available immediately. Visual Builder → Navbar → mobile navigation exposes afterTicker (default true). Desktop cart launcher CSS is always hidden on mobile, even before the nav mounts, and cart UI waits for home configuration to finish loading to avoid the initial cart flash.

The public filter UI now contains only two inline pill buttons: Giá thấp (ascending) and Giá cao (descending). Category, search, volume, range inputs and Apply/Reset buttons are removed from this UI. Tapping a selected sort pill toggles back to the original order. Old category query parameters no longer restrict the sorted public list. Pill labels and typography remain editable in the existing Collection filter settings.

The mobile bottom-navigation lens stretches horizontally and narrows vertically while swiping, with an asymmetric droplet shape following the movement direction. It stays within the bar bounds and springs back to the selected item on release/cancel. Visual Builder → Navbar → mobile navigation → liquidStretch controls the strength (0–2; zero disables stretching). Reduced-motion users receive a plain moving lens.

Product-card actions now use a dedicated stylesheet imported by ProductCard itself. The action row uses grid rather than percentage flex-basis, avoiding height/overflow differences from stylesheet order. Mobile View and cart buttons are both 44px tall and constrained to the card width. Regression checks cover carousel/grid bounds with larger CMS text styles at 320/390/768/1024/1440px. Mobile chat hints are limited to two compact lines and temporarily hidden/inert whenever they would overlap product prices or action controls; scrolling reevaluates that overlap.

The swipe lens now uses a separate raised translucent surface instead of the flat navigation pseudo-element. Dragging expands it across adjacent items, raises its upper edge and magnifies nearby icons; release springs it back to the selected item. A thin chromatic rim is controlled by mobile.rimOpacity (0–1), alongside the existing liquidStretch and iconEffect settings. Reduced-motion and glass-off settings keep simpler rendering.

Desktop product cards now use left-aligned titles and a compact footer with a clear upright price, View button and matching cart button. Visual Builder → Collection → Giá và nút trên card — desktop controls desktop-specific button width/radius/colors, title alignment and price typography; mobile product-card appearance is preserved. Visual Builder → Reviews → Khung thẻ đánh giá controls shared review-card corner radius, border thickness and color, with live preview. Homepage and product review cards use the same style helper; mobile review frames also receive the existing optional glass rim.
